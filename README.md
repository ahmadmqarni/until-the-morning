# Until the morning

A personal daily encouragement page for Ahmad, leading up to the cardiology board on 5 January 2027.

Website: https://ahmadmqarni.github.io/until-the-morning/

## Experience

60 original daily messages with individual typography, composition, and decorative SVG artwork, plus a permanent closing note. Includes a quiet exam countdown, calendar days since postgraduate training began on 1 October 2019, and a previous-days archive.

All dates use Asia/Riyadh. The exam-morning message changes to the closing note at 13:00 Saudi time on 5 January 2027. This is the chosen website transition time, not a verified exam-end time.

## Run locally

Open index.html in a browser. It is self-contained, with no external assets, account, runtime AI calls, or installation required.

## Hosting

GitHub Pages serves the root of the main branch. Edit index.html and commit changes to update the site.

## Notes

All statements are original writing, not quotations attributed to real people. Illustrations are decorative, not diagnostic tracings. The date selection uses the device clock, converted to Saudi time. Future messages are hidden from normal navigation but are bundled in the publicly readable source.
